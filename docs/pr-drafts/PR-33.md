# PR-33: Build the research landing and honest resource simulator

## Problem and scope

The project needs a reviewable public-facing explanation without invented users, earnings, releases or network evidence. Build a separate responsive static landing with an educational planner that exposes actual resource tradeoffs as fictional examples.

[Master plan](../MASTER_PLAN.md), PR-33; dependency packages: [02](PR-02.md). [Scope/evidence ADR](../adr/0001-scope-and-evidence.md). A local implementation boundary does not waive physical, owner or release prerequisites.

## Changes and non-goals

- Create `web/landing/index.html`, native SVG artwork, responsive CSS, local scripts and static build/serve commands.
- Implement pure per-device resource math in `assets/simulator.mjs`: coordinator IO, layer weights, KV/context and scratch, exact contiguous routes, local/full-model alternatives and a real no-route result.
- Label profiles/timings/credits as illustrative; link to real project docs/source and omit fake downloads, waitlists and signup backends.
