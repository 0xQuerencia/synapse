# PR-11: Advertise signed expiring resident model ranges

Local draft for planned review ref `review/pr-11`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

Discovery and capacity hints do not prove that the authenticated worker has the assigned range resident. Bind readiness to signed, expiring model/session/range evidence and reject stale or replayed records.

## Linked plan IDs / ADR / dependency PRs

[Master plan](../MASTER_PLAN.md), PR-11; dependency packages: [06](PR-06.md), [10](PR-10.md). [Scope/evidence ADR](../adr/0001-scope-and-evidence.md). A local implementation boundary does not waive physical, owner or release prerequisites.

## Changes and non-goals

- Implement `SignedAvailability` and a bounded `ReadyRegistry` in `inference/registry.rs`.
- Require signed availability matching the exact `ShardReady`, verify it against the transport peer, and check every planned worker hop.
- Invalidate eligibility on release/disconnect/revocation and preserve sequence watermarks so reconnects cannot replay old readiness.
