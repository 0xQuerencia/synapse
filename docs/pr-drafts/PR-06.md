# PR-06: Prepare authenticated shard leases before generation

Local draft for planned review ref `review/pr-06`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

A connected worker is not necessarily ready with the correct model/range. Add a versioned admission/readiness handshake so generation starts only after all expected authenticated stages echo the exact lease.

## Security, privacy and compatibility impact

Wrong peer, range, model, epoch, duplicate ACK or expired assignment cannot advance readiness. The breaking 0.4 wire contract must be used consistently across nodes.
