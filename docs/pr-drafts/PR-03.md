# PR-03: Pin model identity and verify every input artifact

Local draft for planned review ref `review/pr-03`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

Inference must not load a moving model revision, traverse an untrusted index path or accept a modified tokenizer/configuration. Make model identity include every required input before a backend opens it.

## Linked plan IDs / ADR / dependency PRs

[Master plan](../MASTER_PLAN.md), PR-03; dependency packages: [01](PR-01.md), [02](PR-02.md). [Scope/evidence ADR](../adr/0001-scope-and-evidence.md). A local implementation boundary does not waive physical, owner or release prerequisites.

## Changes and non-goals

- Implement versioned `ModelManifest`/`ModelArtifact`, canonical digest, immutable Hub resolution and bounded filename/index validation in `inference/model_loader.rs`.
- Resolve safetensors weight-map values, deduplicate shard filenames and verify complete local model directories.
- Connect shard file resolution in `inference/pipeline.rs`; pin SHA-256 dependencies through Cargo metadata/lockfile.
