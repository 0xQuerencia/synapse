# PR-51: Enforce signed model rights and verified cache lifecycle

Local draft for planned review ref `review/pr-51`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

Hashes alone do not approve a model publisher or its permitted use. Make the catalog an explicit trust/rights decision and give real callers a quota-bound, verified local cache they can pin through inference.

## Linked plan IDs / ADR / dependency PRs

[Master plan](../MASTER_PLAN.md), PR-51; dependency packages: [03](PR-03.md), [26](PR-26.md), [45](PR-45.md). [Scope/evidence ADR](../adr/0001-scope-and-evidence.md). A local implementation boundary does not waive physical, owner or release prerequisites.

## Changes and non-goals

- Add `crates/synapse-core/src/catalog.rs` for Ed25519 signed records, explicit trust/revocation, purpose-specific rights, bounded JSON and safe local import.
- Stream/hash into private staged files, publish complete content-addressed model views atomically, verify immutable links and prune only unpinned data.
- Expose actual `synapse catalog inspect/import/verify/prune/infer` commands in `crates/synapse-cli/src/catalog.rs` with a retained inference pin, plus an original-fixture example, versioned schemas and independent signature checks in CI.

## Security, privacy and compatibility impact

Unknown/revoked/expired publishers/models and denied hosting/redistribution fail closed. Protected paths, no-follow reads, exclusive writer locks and shared live pins constrain cache operations; no production key or third-party approval is bundled.
