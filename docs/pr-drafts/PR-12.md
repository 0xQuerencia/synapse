# PR-12: Choose feasible routes from bounded measured candidates

Local draft for planned review ref `review/pr-12`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

Memory alone cannot distinguish a useful route from a slow distant chain. Search a bounded set of local, single-worker and contiguous multi-worker candidates with explicit measurement availability.

## Linked plan IDs / ADR / dependency PRs

[Master plan](../MASTER_PLAN.md), PR-12; dependency packages: [09](PR-09.md), [10](PR-10.md), [11](PR-11.md). [Scope/evidence ADR](../adr/0001-scope-and-evidence.md). A local implementation boundary does not waive physical, owner or release prerequisites.

## Changes and non-goals

- Add `inference/routing.rs` and integrate route selection into generation.
- Bound subset search and remote-stage count, retain exact capacity/coverage invariants and deterministic tie handling.
- Use actual Ping RTT and recent matching decode cost; missing/stale calibration produces no latency estimate instead of a fabricated number.
