# PR-07: Load only the assigned transformer and IO tensors

Local draft for planned review ref `review/pr-07`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

Logical layer ranges do not save weight memory if every process loads the full checkpoint. Make tensor ownership explicit and verify the coordinator can own only embedding/head work while workers own their slices.

## Linked plan IDs / ADR / dependency PRs

[Master plan](../MASTER_PLAN.md), PR-07; dependency packages: [05](PR-05.md), [06](PR-06.md). [Scope/evidence ADR](../adr/0001-scope-and-evidence.md). A local implementation boundary does not waive physical, owner or release prerequisites.

## Security, privacy and compatibility impact

Unassigned tensors and unauthorized range execution are rejected. Resident weight counts describe loaded tensors, not total process RSS or GPU allocation.
