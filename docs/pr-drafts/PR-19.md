# PR-19: Harden private security state and local administration

Local draft for planned review ref `review/pr-19`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

Private networking still crosses identity, local filesystem, untrusted frame and browser boundaries. Correct concrete race/permission/abuse weaknesses and record the remaining security limits before a wider pilot.

## Changes and non-goals

- Harden `identity.rs`, pairing rate limits, codec malformed-input handling and health/connection state.
- Make GUI tokens/configuration bounded, owned, no-follow and atomically persisted in `auth.rs` and `config_io.rs`.
- Record threat/control regressions in `docs/evidence/private-security.md` and `local-admin-security.md`; leave independent audit and physical WAN gates explicit.

Global and per-peer bounds resist identity churn; corrupt state fails closed; concurrent creation/revocation cannot expose partial secrets or lose durable revocations. Browser Host/Origin/authentication remains enforced.
