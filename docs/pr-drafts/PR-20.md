# PR-20: Provide a bounded full-model execution backend

Local draft for planned review ref `review/pr-20`. This file does not open a GitHub PR or grant acceptance. Review refs are chronological integration boundaries; related follow-ups can occur in later entries of the stack.

## Problem and scope

A remote/local full-model route needs one real execution contract with limits, cancellation and streaming behavior. Wrap the validated Candle loader so the API does not bypass architecture, context or weight admission.

## Linked plan IDs / ADR / dependency PRs

[Master plan](../MASTER_PLAN.md), PR-20; dependency packages: [04](PR-04.md), [19](PR-19.md). [Scope/evidence ADR](../adr/0001-scope-and-evidence.md). A local implementation boundary does not waive physical, owner or release prerequisites.

## Changes and non-goals

- Implement backend requests, prompt selection, load limits, generation events and cancellation in `crates/synapse-core/src/backend.rs`.
- Reuse verified local model manifests and validated Llama implementations; reject unsupported request/model combinations.
- Later follow-ups validate GGUF sidecar/config agreement before allocation and use explicit CPU execution dtype accounting.
