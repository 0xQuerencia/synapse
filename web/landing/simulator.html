What this example counts

Per-device memory includes assigned layer weights, context-dependent KV cache and working memory. In a sharded route, the laptop also holds input and output weights. A full-model host holds every component.

The fictional decode estimate includes per-layer compute, coordinator overhead and activation round trips. Full-model text streaming avoids the per-token round trip between layers.

The budgets assume operating-system headroom and devices that support the same model and format. The estimates omit load, queue and prefill time.
