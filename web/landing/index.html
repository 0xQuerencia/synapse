The idea

One machine has limits.
A network opens possibilities.

A model can be too large for one computer's memory. Synapse explores assigning consecutive transformer layers to compatible, trusted devices—then coordinating them as one inference session.

Sharing capacity brings tradeoffs. Network latency matters. Every device needs enough room for its own weights, cache and working memory. More computers do not automatically mean a faster answer.

What this example counts

Per-device memory = assigned layer weights + context-dependent KV cache + working scratch. In a sharded route, the laptop also holds input/output weights. A full-model host holds every component.

From your desk to another city

Different Wi-Fi.
Still part of the idea.

Wi-Fi connects a device to its router. The internet connects separate networks. The target architecture uses authenticated direct connections, with bounded relays when routers prevent a direct path.

Real distance, router and relay claims require measured trials. Simulated latency does not establish a successful inter-city connection.

Good questions

A little more clarity.

Is this like BitTorrent for AI?

The cooperative idea is similar. Model seeding shares verified files; inference needs ordered computation, compatible weights, session state and a complete route. Synapse aims to support both, with different responsibilities and checks.

Can my laptop run a model larger than its memory?

That is the goal of layer sharding. It depends on the model, format, context, per-device memory and compatible peers. Real-device memory measurements and correct output are required before making a supported-capability claim.

Do more devices make it faster?

Not necessarily. Slow devices or network links can make a route worse. A capable full-model host may be the best choice. Sharding is especially useful when no single eligible device fits the model.

Can I earn money?

No cash rewards are planned. The proposed closed-loop credits represent access to eligible community compute. They do not guarantee demand, value, availability or future earnings.

Is my prompt private?

Local computation stays on your device. Trusted private clusters add the peers you approve. Remote workers may see prompts or infer information from activations. Do not assume transport encryption makes an untrusted worker confidential.

What happens if a worker leaves?

The runtime needs bounded recovery with compatible capacity, or a clear terminal failure. Community jobs additionally need validated partial settlement and unused-credit release. These behaviors have separate tests and acceptance gates.

What can I download today?

This site makes no claim of a verified binary release. Use the source repository and reproduction guide. Signed packages, independent installation tests and a supported-platform matrix are part of the release gate.
