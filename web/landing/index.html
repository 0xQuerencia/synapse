Model fit

Fit a model across machines.

When a model exceeds one machine’s available memory, splitting it into consecutive layer ranges can make it fit across compatible devices. The coordinator keeps the input and output weights. Each participant needs room for its layers, cache and working memory.

Each generated token depends on the machines passing intermediate results in order. Link latency and per-device memory budgets shape which splits are practical.
