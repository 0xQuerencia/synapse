Contribute your compute

Your machine runs part of the model and shares the work. This takes a real program — a browser tab can't compute — but it's three steps.

host status checking…
model

pairing code
--------
1

Get Synapse on your machine

Clone and build it (needs Rust). One-time setup.

git clone https://github.com/rickyparmar-bot/synapse.git
cd synapse
cargo build --release -p synapse-gui

No Rust? Install via https://rustup.rs first.

2

Open your own Synapse GUI

Run it locally and open the link it prints (your own localhost).

./target/release/synapse-gui

Then open http://127.0.0.1:8080 → go to Network.

3

Download → Compute test → Join

Once your own GUI is running, use the link below — it opens your join panel with the model and pairing code already filled in:

Open my join page (pre-filled)

Assumes your GUI runs on the default 127.0.0.1:8080. If you started it on a different port, fill the panel manually:

  1. Download model — set it to …
  2. Run compute test — measures your machine's score
  3. Paste the host's code …, then Join as worker
Host address: ask the host for their reachable address. Same WiFi → auto-discovered (mDNS), leave blank. Different networks → you need a shared VPN (Tailscale is free) or relay address in the form /ip4/<ip>/udp/<port>/quic-v1.

Why a download? Contributing compute means running model layers + peer-to-peer networking, which a browser can't do.

Networking: on the same WiFi it just works. Across the internet both machines are behind NAT — you'll need Tailscale or a relay.
